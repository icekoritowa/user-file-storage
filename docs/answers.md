# Ответы на контрольные вопросы

## 1. Какие основные типы данных используются в Python?

Простые типы: int, float, str, bool; отсутствие значения обозначается None. Также есть list, tuple, dict и set, изучаемые далее.

## 2. Чем отличаются int, float, str и bool?

int хранит целые числа, float — числа с плавающей точкой, str — текст, bool — True или False.

## 3. Для чего используется преобразование типов?

Для получения значения нужного типа: int("13107200") преобразует текстовый размер в целое число для вычислений.

## 4. Какие операции можно выполнять со строками?

Объединение через +, повторение через *, сравнение, поиск, срезы, получение длины, замена и изменение регистра.

## 5. Какие операторы сравнения используются в Python?

==, !=, <, >, <=, >=. Результат обычного сравнения — bool.

## 6. Для чего используется конструкция if?

Для выполнения блока кода при истинности условия.

## 7. В чем различие между if, elif и else?

if задаёт первое условие; elif проверяется, если предыдущие условия ложны; else выполняется, если ни одно не подошло.

## 8. Как записываются составные условия?

Условия соединяются and, or и not; скобки задают явный порядок: is_owner or access == "write".

## 9. Для чего используются and, or и not?

and требует истинности обоих условий, or — хотя бы одного, not инвертирует истинность. and и or вычисляют правый операнд только при необходимости.

## 10. Что такое модуль Python?

Модуль — единица организации кода, обычно файл .py с определениями и инструкциями.

## 11. Для чего используется import?

Для подключения модуля и использования его функций, классов и значений.

## 12. Чем импорт модуля отличается от импорта объекта?

import datetime требует обращения datetime.date; from datetime import date позволяет обращаться прямо к date.

## 13. Для чего используется виртуальное окружение?

Для изоляции интерпретатора и пакетов проекта от зависимостей других проектов.

## 14. Что такое IDE?

Интегрированная среда разработки: редактор с запуском программы, отладчиком и другими средствами разработки.

## 15. Для чего используется Git?

Для сохранения истории версий, сравнения изменений и совместной разработки.

## 16. Что такое репозиторий?

Хранилище проекта вместе с историей изменений и служебными данными Git.

## 17. Что такое commit?

Зафиксированный снимок состояния файлов с сообщением, автором и ссылкой на предыдущую историю.

## 18. Для чего нужен .gitignore?

Он указывает неотслеживаемые файлы, которые Git должен игнорировать, например .venv и кэши. Уже отслеживаемые файлы автоматически не удаляются.

## 19. Для чего нужен README.md?

Для описания назначения проекта, установки, запуска, функций и дальнейшего развития.

## 20. Что такое отладка?

Поиск причин ошибок путём наблюдения за выполнением программы и исправления кода.

## 21. Что такое breakpoint?

Точка, в которой отладчик приостанавливает выполнение программы для просмотра её состояния.

## 22. Для чего нужно пошаговое выполнение?

Чтобы увидеть, как конкретные инструкции меняют значения переменных и ход выполнения.

## 23. Какую задачу решает приложение?

Организацию хранения пользовательских файлов по папкам с квотами и разграничением доступа.

## 24. Кто предполагаемый пользователь?

Студенты, преподаватели и небольшие рабочие группы.

## 25. Какие основные сущности выделены?

Пользователь, файл, папка и доступ. Доступ связывает пользователя с папкой и уровнем разрешений.

## 26. Какие функции планируется реализовать?

Реальную загрузку, скачивание, удаление и перемещение файлов, управление папками и выдачу доступа.

## 27. Какой сценарий реализован сейчас?

Проверка возможности загрузки файла: права на папку, квота и сообщение с остатком места либо причиной отказа.

## 28. Какие конструкции Python использованы?

Простые типы, преобразование int, арифметика, сравнения, if, and/or/not, функции, f-строки и импорт date.

## 29. Что добавится после ООП и Django?

Классы сущностей, модели базы данных, веб-страницы, формы, регистрация и серверная проверка прав.

## 30. Почему область подходит для веб-приложения?

Есть связанные сущности, постоянные данные, несколько пользователей, операции CRUD и необходимость доступа через браузер и API.
