# Отладка ПР1

Выполнен реальный сеанс стандартного отладчика Python `pdb`.
Полный вывод сохранён в [debug-session.txt](debug-session.txt).
IDE в этой среде не управлялась; ниже приведены шаги для повторения в VS Code.

## Ошибка и исправление

Во временной копии `main.py` в `has_space` условие `used_space + file_size <= quota`
заменено на `used_space + file_size < quota`. Размер демонстрационного файла изменён на 20 МиБ.
При занятых 80 МиБ и квоте 100 МиБ программа ошибочно отклоняет точное заполнение.

В pdb установлена точка останова на строке сравнения, выполнены `continue`,
просмотр переменных через `p`, шаг `next` и просмотр возвращаемого значения.
Наблюдаемые значения: `file_size = 20971520`, `used_space = 83886080`,
`quota = 104857600`, сумма равна квоте. Ошибочная версия возвращает `False`.
После замены `<` на `<=` тот же сеанс возвращает `True`.
В основной версии сохранено исправленное условие; граничный случай проверяется pytest.

## Повторение в IDE

1. Открыть проект в VS Code с расширениями Python и Python Debugger.
2. Выбрать Python из `.venv`; в `main` временно задать `file_size = 20 * MIB`.
3. В `has_space` временно заменить `<=` на `<` и поставить breakpoint на строке сравнения.
4. Нажать F5, выбрать конфигурацию проекта; посмотреть размеры в панели Variables.
5. Нажать F10, убедиться в ошибочном результате при равенстве суммы и квоты.
6. Восстановить `<=`, повторить запуск, затем вернуть размер файла 12,5 МиБ.
7. Выполнить `python -m pytest -q`.
