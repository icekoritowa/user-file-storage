## Показ преподавателю

1. В терминале открыть папку проекта, выполнить `git pull`, затем `bash run_web.sh`.
2. Открыть http://127.0.0.1:8000/. Показать главную, счётчики, навигацию и логотип.
3. Открыть «Папки» → папку → файл. Показать владельца, квоту, дату и размер.
4. Открыть «Доступ» → право пользователя → папку. Показать обозначение read/write.
5. Нажать «Тёмная тема» и «Светлая тема».
6. Открыть `/files/999/`, показать страницу 404.
7. В редакторе показать templates/base.html, includes/navigation.html,
   library/templates/library/folder_list.html и includes/folder_card.html:
   extends, block, include, for/empty, url, length и default.
8. Показать library/views.py: контекст и render; затем файл CSS и main.js.
9. Во втором терминале с активным окружением показать check, pytest, flake8
   и `git log -1 --oneline` с префиксом PR6:.

Если своего data/catalog.json ещё нет, сайт показывает готовый data/example.json.
Для личных данных добавлять записи и менять права следует через `python3 main.py`,
после сохранения обновлять страницу. Веб-часть пока только отображает каталог.
