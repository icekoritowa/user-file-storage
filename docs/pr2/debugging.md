# Отладка ПР2

Фактически выполнен сеанс стандартного отладчика pdb; вывод — в debug-session.txt.
Точка останова поставлена внутри цикла check_access на сравнении user_id и folder_id.

Подготовлены владелец ilya (1), гость guest (2), папка Учеба (1) и доступ read.
В точке останова проверены user_id=2, folder_id=1 и текущий словарь entry.
Команда next пошагово проходит присваивание access и выход из цикла.
При write=False возвращается True, при write=True — False: чтение разрешено,
загрузка запрещена. Это проверяется и тестом жизненного цикла доступа.

Повторение в IDE: открыть проект, выбрать Python из .venv, поставить breakpoint
в цикле check_access, запустить main.py с примером данных. Переключиться на гостя
через пункт 3 и вывести файлы через пункт 6. Посмотреть entry и access в Variables,
выполнить F10; затем попробовать загрузку через пункт 7. Гость с read получает отказ.
В среде выполнения проверен pdb; интерактивная демонстрация IDE остаётся для защиты.
