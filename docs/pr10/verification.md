# ПР10 — административная панель и запросы

Модели User, Folder, File и Access зарегистрированы в admin.py.
Интерфейс локализован: приложения, модели, поля и название панели.
Настроены list_display, search_fields, list_filter, ordering, list_select_related,
autocomplete_fields, date_hierarchy и встроенные списки связанных записей.
Встроенные списки доступны для просмотра, отдельные формы — для изменения.

Миграции добавляют slug папки и вычисляемое поле File.is_large.
Адреса существующих папок заполняются отдельной миграцией данных перед
установкой NOT NULL. Старые адреса по ID продолжают работать.
Значения уровней read/write сохранены при переходе на TextChoices.

QuerySet содержит повторно используемые методы получения связанных объектов,
отбора непустых файлов, фильтрации даты и уровней доступа. Общий контекстный
процессор передаёт название сайта без запросов в базу.
