## Назначение

Сервис для хранения личных файлов, организации их по папкам и предоставления доступа другим пользователям.

## Целевая аудитория

Студенты, преподаватели и небольшие рабочие группы, которым нужно хранить документы и обмениваться ими.

## Предметная область

Пользователь владеет папками и файлами. Размер хранилища ограничен квотой владельца.
Доступ связывает другого пользователя с папкой и определяет возможность чтения или записи.
В ПР1 право передаётся функции как исходное доверенное значение; это учебная модель, а не система аутентификации.

## Основные сущности

- Пользователь: имя, идентификатор, квота. Владеет несколькими папками и файлами.
- Файл: имя, размер в байтах, владелец, папка, дата загрузки.
- Папка: имя, владелец, родительская папка; содержит файлы.
- Доступ: пользователь, папка, уровень `read` или `write`.

На ПР1 сущности представлены простыми переменными; классы и база данных пока не используются.

## Основные функции

Уже реализованы три функции предметной области:

1. `can_write` — проверяет возможность записи: владелец или получатель права `write`.
2. `has_space` — проверяет неотрицательные размеры и достаточность квоты, включая точное заполнение.
3. `upload_file` — моделирует загрузку файла в указанную папку: проверяет имена, права и квоту, выдаёт результат и остаток места.

`main` демонстрирует один законченный сценарий с успешным исходом и двумя отказами.
Файлы физически не сохраняются, квота не изменяется между вызовами; каждая проверка независима.
Размеры передаются целыми байтами, 1 МиБ = 1 048 576 байт. Пустой файл допустим.
Используются `str`, `int`, `float`, `bool`, преобразование `int`, арифметика, сравнения, `if`, логические операции, функции и импорт `datetime`.

## Запуск и проверка

Нужен Python 3.10 или новее. Для самого приложения сторонние пакеты не нужны.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python main.py
python -m pytest -q
python -m pycodestyle main.py tests
```

Windows: вместо `source` выполнить `.venv\Scripts\activate`.
Для IDE можно открыть папку в VS Code, установить расширения Python и Python Debugger,
выбрать интерпретатор `.venv` и конфигурацию «ПР1: отладка main.py».

Ожидаемые исходы демонстрации: загрузка 12,5 МиБ при занятых 80 из 100 МиБ разрешена,
остаток 7,5 МиБ; гостю с правом чтения отказано; файл 21 МиБ превышает квоту.
